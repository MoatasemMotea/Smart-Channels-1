# Smart Channels — Corporate Website

Bilingual (EN `/en` · AR `/ar`, true RTL), dark/light themed, cinematic
technology-experience website for Smart Channels. Built with Next.js
(App Router), TypeScript (strict), Tailwind CSS v4 and next-intl.

> This README covers the development foundation (P3). The full owner
> maintenance guide is delivered at P19 — until then see
> `docs/maintenance-model.md` for the owner-editability contract and
> `docs/` for the complete project documentation set.

## Requirements

- Node.js **20+** (LTS) — `npm` included
- ffmpeg — only needed when processing new videos (`npm run media`)

## Quickstart

```bash
npm install          # reproducible via package-lock.json
npm run dev          # http://localhost:3000 → redirects to /en or /ar
```

Production build and local run:

```bash
npm run build
npm start
```

## Everyday commands

| Command | Purpose |
|---|---|
| `npm run check` | typecheck + lint + content validation + unit tests |
| `npm run validate` | content validation (dev mode — AR gaps are warnings) |
| `npm run validate:release` | release mode — AR gaps are blocking (A-002) |
| `npm run media` | generate public media derivatives + video posters for approved records |
| `npm run test:smoke` | Playwright smoke suite (run after `npm run build`) |
| `npm run format` | Prettier |

## Where things live

| What | Where |
|---|---|
| Business content (stats, solutions, projects, gallery, partners, clients, contact, nav) | `src/content/` — data only, never components |
| UI strings EN/AR | `src/messages/en.json` / `ar.json` |
| Content schemas | `src/types/content.ts` (mirrors `docs/content-model.md`) |
| Accessors + publish filtering | `src/lib/content/` |
| Design tokens & themes | `src/styles/globals.css` (single source of brand color) |
| Fonts (self-hosted, SIL OFL) | `public/fonts/` |
| Source media archive (never served) | `media-source/` — see its README |
| Approved public media | `public/media/` (generated by `npm run media`) |
| Project documentation & decisions | `docs/` (start with `decision-log.md`) |
| P2 design boards | `design/boards/` |

Routine content changes are **data edits only** — adding gallery media,
changing Track Record values, toggling featured industries, adding
partners/clients never touches a React component
(`docs/maintenance-model.md` has the task→file map).

## Notes

- Indexing is **disabled by default** (noindex + robots disallow); the
  authorized production deployment must set
  `NEXT_PUBLIC_ALLOW_INDEXING=true` explicitly.
- No analytics provider is connected (`src/lib/analytics.ts` is a no-op
  by design until one is approved).
- Legacy `img/` photos are pending owner media review (O-008) and are not
  used by the application.
