# Archived Arabic fonts (D-088)

Removed from the website at D-088 (Arabic text now uses the system Arial
stack). Kept here as the archive, and as the source font for the static
Open Graph images (`scripts/generate-og.ts`). Both families are licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org/).

| Family | Files | Copyright |
|---|---|---|
| Noto Kufi Arabic | `notokufi-1…5.woff2` | Google / Noto Project |
| IBM Plex Sans Arabic | `plexarabic-1…16.woff2` | IBM Corp. (Bold Monday) |

The `unicode-range` and weight of each file are recorded in the git history
of `public/fonts/fonts.css` (before D-088).
