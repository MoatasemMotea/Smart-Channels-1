# SOURCE MATERIAL — NOT PUBLIC WEBSITE CONTENT

**D-020 (owner ruling, P4 Revision 2):** the Company Profile PDF in this
directory is the private source of truth for approved company information.

It must NEVER be:

- copied into `public/` (anything there is directly web-accessible);
- linked, embedded, served, or offered for download on the website;
- exposed through any route, sitemap entry, or generated derivative.

It remains archived here only for provenance, content verification, and
future owner reference. `npm run validate` fails the build if any PDF
appears under `public/` or any Company Profile record is publicly enabled.

Use the approved information. Do not publish the source document itself.
